# One's Dotfiles collection

Feel free to use :)
![Fedora+Hyprland](https://github.com/yuchanns/dotfiles/assets/25029451/1b35ee0e-94ab-45ba-8d7c-f31e7114ad9b)

Hyprland and Eww use the Hypringo submodule included in this repository.
Initialize it after the first checkout:

```bash
git submodule update --init --recursive
```

The submodule follows `ltask-runtime`, while its gitlink pins the exact
validated compiled-runtime revision. See [Hyprland](hypr/README.md) and
[Eww](eww/README.md) for installation details.
